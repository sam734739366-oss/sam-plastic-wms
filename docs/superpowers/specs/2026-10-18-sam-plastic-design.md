# وثيقة تصميم برنامج «سام بلاستيك»

برنامج سطح مكتب (Windows) لإدارة مصنع نفخ العبوات البلاستيكية: مخازن، مشتريات، مبيعات، تصاريح صرف واستلام، نفخ للغير، تقارير وطباعة.

التاريخ: 2026-10-18 — الحالة: معتمدة من المستخدم قسمًا بقسم.

## القرارات المعتمدة

| القرار | الاختيار |
|---|---|
| بيئة التشغيل | جهاز واحد فقط (قابل للتوسع لاحقًا) |
| المستخدمون | المدير (صلاحية كاملة) + إمكانية إضافة أدوار لاحقًا |
| الطباعة | A4 و A5 حسب نوع المستند، معاينة قبل الطباعة |
| العملة | ريال يمني |
| التقنية | Electron + SQLite (ملف قاعدة واحد + نسخ احتياطي + مزامنة سحابية) |
| التكويد | يدوي بنظام المجموعة-الرقم (مثل 001-001) |
| اللغة | واجهة عربية كاملة RTL |

---

## 1) شاشات البرنامج

- **تسجيل الدخول**: اختيار مستخدم + كلمة مرور.
- **الرئيسية**: أرصدة المخازن، عمليات اليوم، ملخص إنتاج اليوم (سليم/تالف) لكل وردية.
- **بيانات أساسية**: الأصناف، الموردون والعملاء، المكائن، الورديات (صباحية/مسائية)، المخازن، المستخدمون، إعدادات المصنع (ترويسة الطباعة، مسار النسخ الاحتياطي، المجلد السحابي).
- **الحركات اليومية**:
  - فاتورة شراء خام (كرتون مرقّم أو وزن، بتكلفة)
  - تصريح صرف خام للإنتاج (كراتين بأرقامها أو وزن + مكينة + وردية + مستلم)
  - تسجيل نتيجة الإنتاج (لكل كرتون: سليم/تالف قبل/تالف بعد)
  - تصريح استلام إنتاج تام (علب/كيس/وزن)
  - فاتورة بيع / تصريح خروج (اسم السائق + رقم السيارة)
  - التالف ومصيره (محرز/مخزون/استرجاع مورد/بيع خردة)
  - النفخ للغير: استلام خام عميل، تسليم منفوخ، فاتورة أجرة نفخ، رصيد العميل
  - نقل بين المخازن (داخل/خارج المصنع)
  - صرف مواد تشغيلية
- **التقارير**: حركة صنف، الإنتاج، التالف، رصيد العملاء، المشتريات والمبيعات، جرد المخزون، سجل التدقيق.
- كل شاشة حركة: ترقيم يدوي، تاريخ، ملاحظات، معاينة وطباعة A4/A5.

## 2) الأصناف والوحدات والتحويلات

### المجموعات الخمس (من ملف الأصناف المرسل من المستخدم)

| المجموعة | الكود | الأمثلة | الوحدة | بيانات العبوة |
|---|---|---|---|---|
| 1) المواد الأولية | 001-xxx | امبولات بوزنها بالجرام (5.02، 23، 61، 5.13...) جديد ومحرز (صنفان منفصلان بأكواد مختلفة) + أغطية + أكياس تعبئة + شيالات | امبولة/حبة/كيس | عدد الحبات بالكرتون (12800، 8064، 5500، 960...) |
| 2) الإنتاج التام | 002-xxx | علب بكل الأحجام (مل/لتر) | علبة | عبوة الكيس عند الاستلام من الإنتاج أو البيع (100-500 علبة) |
| 3) خام للغير | 003-xxx | امبول خام صغير/كبير للغير | علبة/امبولة | عدد الامبولات بالعلبة **يُدخل عند كل استلام** (يختلف حسب العميل) |
| 4) الخدمات | 004-xxx | نفخ علب بلاستيك صغير/كبير/مفيد | علبة | سعر أجرة النفخ لكل علبة (قابل للتعديل) |
| 5) توالف الإنتاج | 005-xxx | تالف تام، تالف علب صغير/كبير وللغير | علبة | توالف "للغير" مرتبطة بكل عميل على حدة |

### بيانات الصنف
كود يدوي، اسم، المجموعة، الوحدة الأساسية، الوزن بالجرام، عدد حبات الكرتون/الكيس، سعر الخدمة، ملاحظات.

### القاعدة الذهبية للتحويل
كل صنف يُرجع إلى الحبة (القطعة). من وزن الحبة تُحسب كل الوحدات تلقائيًا:
- الوزن (كجم) = عدد الحبات × الوزن بالجرام ÷ 1000
- الكرتون = عدد الحبات ÷ عدد حبات الكرتون
- الكيس = عدد الحبات ÷ عدد حبات الكيس
- الطن = كجم ÷ 1000

الإدخال بأي وحدة (حبة/علبة/كيس/كرتون/كجم/طن) والعرض بكل الوحدات معًا في الإدخال والمخزون والتقارير.

## 3) سير العمل

### أ) خام المصنع
شراء (فاتورة من مورد، كراتين مرقمة تلقائيًا أو وزن، بالتكلفة بالريال) ← صرف للإنتاج (تصريح: كراتين بأرقامها أو وزن + مكينة + وردية + مستلم) ← تسجيل النتيجة لكل كرتون (سليم/تالف قبل/تالف بعد بالحبة والوزن) ← استلام تام (تصريح: علب/كيس/وزن) ← بيع (فاتورة) أو خروج (تصريح + سائق + سيارة).

مصير التالف — كل الاحتمالات مدعومة:
- يرجع للمخزن كمحرز (بالوزن)
- يرجع للمخزون كقطع (بالحبة أو الوزن)
- استرجاع للمورد (مرتجع شراء)
- يُباع كخردة (فاتورة بيع خردة)

### ب) نفخ للغير
1. استلام خام من العميل (مستند أمانة) بالعلب مع إدخال عدد الامبولات في كل علبة عند الاستلام ← يُحتسب رصيد امبولات العميل.
2. صرف للماكينة بتصريح صرف مع اسم العميل.
3. تسجيل النتيجة (سليم/تالف) — توالف للغير تُسجل لكل عميل على حدة وتظهر في رصيده.
4. تسليم المنفوخ للعميل (مستند تسليم) — ينقص تلقائيًا من رصيد امبولات العميل (امبولة = علبة).
5. فاتورة أجرة النفخ (صنف خدمة 004 بسعر لكل علبة).
6. تقرير رصيد كل عميل: استلم خام / سلّمنا تام / التالف / الباقي لدينا.

### ج) حركات أخرى
نقل بين المخازن، صرف مواد تشغيلية، شراء وبيع أصناف تجارية بدون إنتاج (أغطية بالكرتون/الحبة/الوزن).

كل مستند: ترقيم يدوي، تاريخ، ملاحظات، معاينة وطباعة، قابل للتعديل/الإلغاء من المدير مع أثر فوري على الأرصدة.

## 4) قاعدة البيانات (SQLite)

| الجدول | المحتوى |
|---|---|
| `items` | الأصناف بكل بياناتها |
| `parties` | الموردون والعملاء (دفتر عناوين) |
| `warehouses` / `machines` / `shifts` | مخازن (داخل/خارج)، مكائن، ورديات |
| `users` | مستخدمون بأدوار وصلاحيات |
| `purchases` + `purchase_items` | فواتير الشراء وبنودها |
| `cartons` | الكراتين المرقمة: رقم، صنف، فاتورة شراء، حالة (بالمخزن/مصروف/منتهي)، تاريخ الصرف، النتيجة |
| `issue_permits` + `issue_items` | تصاريح الصرف (مكينة، وردية، مستلم، خام مصنع أو عميل) |
| `production_results` | نتيجة كل كرتون: سليم/تالف قبل/تالف بعد |
| `receive_permits` + `receive_items` | تصاريح استلام التام |
| `invoices` + `invoice_items` | فواتير البيع (بيع/خردة/أجرة نفخ) + سائق وسيارة |
| `exit_permits` | تصاريح الخروج بدون بيع |
| `customer_raw_receipts` | استلام خام العميل (عدد الامبولات بالعلبة عند الاستلام) |
| `customer_deliveries` | تسليم المنفوخ للعميل (ينقص رصيد امبولاته) |
| `scrap_movements` | مصير التالف |
| `transfers` | النقل بين المخازن |
| `stock_moves` | **دفتر حركات المخزون**: تاريخ، رقم مستند، صنف، مخزن، وارد/منصرف بالحبة والوزن |
| `audit_log` | سجل التدقيق: مستخدم، وقت، عملية، قيم قبل/بعد |
| `settings` | ترويسة الطباعة، مسار النسخ الاحتياطي، المجلد السحابي |

**مبدأ جوهري:** الأرصدة لا تُخزن أبدًا — تُحسب دائمًا من `stock_moves`. أي تعديل أو إلغاء لأي مستند يعيد حساب الرصيد تلقائيًا.

## 5) الصلاحيات والتدقيق

| الدور | الصلاحية |
|---|---|
| المدير | كل شيء: إضافة، تعديل، حذف — مع نافذة تحذير تعرض التداعيات قبل التنفيذ |
| مستخدم إدخال | إضافة وتعديل عمليات اليوم فقط، بدون حذف |
| عرض فقط | تصفح وتقارير فقط |

**قواعد التداعيات:**
- مستند مرتبط بعمليات لاحقة → لا يُحذف نهائيًا، بل "إلغاء مستند" يعكس الأثر ويبقى في التقارير بعلامة ملغى. الحذف النهائي للمدير فقط بعد تحذير مفصّل.
- تعديل كمية/صنف في مستند → إعادة حساب الأرصدة تلقائيًا + نافذة "أثر التعديل" (قبل ← بعد) قبل الحفظ.
- سجل التدقيق: كل تعديل/حذف/إلغاء/طباعة (من، متى، قبل/بعد).

## 6) التقارير والطباعة

- **حركة صنف**: كل حركة بتاريخها ورقم مستندها ونوعه + وارد/منصرف + رصيد تراكمي — بالحبة والوزن — خام أو تام أو تجاري.
- **تقرير الإنتاج**: لكل كرتون رقمه وتاريخ صرفه والمكينة والوردية والنتيجة (سليم/تالف قبل/تالف بعد).
- **تقرير التالف ومصيره**.
- **رصيد العملاء (خام للغير)**: استلم/سلّمنا/تالف/الباقي.
- **المشتريات والمبيعات**: بالتكاليف بالريال + كشف حساب مورد/عميل + فواتير أجرة النفخ.
- **جرد المخزون**: كل الأصناف بكل المخازن بالحبة والكرتون/الكيس والوزن.
- **سجل التدقيق**.

كل تقرير: فلترة (تاريخ/صنف/مخزن/مورد/عميل) + معاينة + طباعة A4 + تصدير Excel/PDF.

**الطباعة الموحدة:** معاينة قبل الطباعة لكل المستندات، A4 أو A5 حسب نوع المستند (تُحفظ التفضيلات)، ترويسة المصنع من الإعدادات، ومطابقة النماذج الورقية الحالية (صور يرسلها المستخدم عند كل مرحلة).

## 7) النسخ الاحتياطي والمزامنة

- ملف نسخة واحد `سام-بلاستيك-نسخة-YYYY-MM-DD.sambak` يحوي كل البيانات.
- تلقائيًا: يوميًا + عند إغلاق البرنامج + زر "نسخ الآن".
- شاشة استرجاع من أي ملف نسخة.
- مزامنة سحابية: نسخ تلقائي للملف إلى مجلد يحدده المستخدم (Google Drive/Dropbox/OneDrive على الجهاز) + خيار رفع مباشر لحساب Google Drive.

## 8) مراحل التنفيذ (كل مرحلة يعاينها المستخدم قبل التالية)

| المرحلة | المحتوى | يرسل المستخدم عندها |
|---|---|---|
| 1. الأساس | قاعدة البيانات، تسجيل الدخول، الإعدادات، المخازن/المكائن/الورديات | تجربة عامة |
| 2. الأصناف | المجموعات الخمس + إدخال ملف الأصناف + الموردون والعملاء | ملف الأصناف النهائي إن تغير |
| 3. الشراء والصرف | فواتير الشراء + ترقيم الكراتين + تصاريح الصرف | صورة نموذج تصريح الصرف |
| 4. الإنتاج | نتيجة كل كرتون + تصاريح استلام التام | صورة نموذج تصريح الاستلام |
| 5. النفخ للغير | استلام خام عميل، تسليم منفوخ، فاتورة أجرة، رصيد العميل | صور نماذجها إن وجدت |
| 6. البيع والخروج | فواتير البيع + تصاريح الخروج + التالف + نقل المخازن | صورة نموذج فاتورة الخروج |
| 7. التقارير والطباعة | كل التقارير + المعاينة والطباعة A4/A5 | تجربة الطباعة |
| 8. الحماية والإطلاق | النسخ الاحتياطي والسحابة + التثبيت النهائي + فحص شامل | تجربة الاسترجاع والتثبيت |

## 9) نقاط مؤجلة للتوضيح عند مراحلها

- صور النماذج الورقية لتصريح الصرف/الاستلام وفاتورة الخروج (يرسلها المستخدم عند كل مرحلة).
- تفاصيل تسعير أجرة النفخ (السعر لكل علبة قابل للتعديل لكل صنف خدمة).
- طريقة الرفع المباشر لـ Google Drive (تتطلب تفعيل حساب Google عند مرحلة الحماية).
- كمية بالات الخام المخلطة (كبير/وسط/صغير — سليم/تالف/معيب) ستُضاف عند وجود بيانات فعلية عنها.
